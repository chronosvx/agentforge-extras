# 合规与数据安全说明

## 数据出境风险

- 当你使用 `--provider openai` 等国外厂商时，会话内容可能发送到境外服务器。
- 请确认你的业务是否允许数据出境，并遵守所在地区法律法规（如中国《数据安全法》《个人信息保护法》）。
- 使用前建议：
  - 优先选择国内厂商（DeepSeek、Moonshot、智谱、Qwen、豆包等）
  - 确需使用国外厂商时，对敏感内容脱敏后再发送
  - 使用 `--confirm-data-export` 表示已知晓并同意

## 本地数据存储

- 默认本地会话为 JSON 文件存储。
- 可通过 `internal/session.EncryptedStore` 或后续 CLI 开关启用加密存储。
- 审计日志默认记录关键操作，并自动脱敏。

## 遥测

- 默认关闭。
- 开启后仅本地写入 `telemetry.log`，不联网、不收集敏感信息。

## 项目性质

- 本项目为个人项目，主要用于个人学习与日常使用。
